# varun-manjunath27.github.io

Static academic homepage. No build step.

- `index.html` — home page (edit the News list and publications here)
- `projects/` — one page per paper
- `assets/images/bio.jpg` — portrait
- `cv/CV_Varun.pdf` — add your compiled CV here (keep the filename)
- `papers/`, `slides/` — add PDFs, then uncomment the matching links in the HTML

Preview locally: `python3 -m http.server 8000`, then open http://localhost:8000
